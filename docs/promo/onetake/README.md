# 纸盒 · 一个纸箱（60 秒 · 一镜到底）

用 [onetake](https://github.com/feitangyuan/onetake) 做的一支产品短片。全片只有一个物体：
一个牛皮纸箱。它闭着、被掀开、镜头钻进箱内、箱底那块面变成屏幕、屏幕上发生的事一件件长出来；
最后一切折回箱子、合盖、压平，压平的那块面就是「纸盒」两个字。

- 成片：`../纸盒-一个纸箱-60s.mp4`（1920×1080 · 30fps · 60.0s · H.264 + AAC）
- 画面：`comp.html`（一份 HTML，`window.__seek(t)` 纯函数）
- 声音：`sound.py` → `sfx.wav`（say 的中文解说 + 一套共用混响的合成音效）

## 声音

`sfx_palette` 的五个材料（air / wood / glass / sub / bubble）在同一个 T60=1.25s 的房间里：

- 掀盖 = 低频 air + 一记木响 + 盖板翻过去那一下的 sub
- 下潜 = 一路往上抽的 air（130→3200Hz）
- 打字 = 每个字一记 210Hz 的木响，摆在同一格上
- 水波 = bubble + 一片扫出去 air + 一个高玻璃泛音
- 三条步骤 / 三行打勾 / 字标 = 玻璃音一个比一个高（523 / 622 / 740；392 / 494 / 587）
- 合盖两记：木 110 + sub 50，落定那记更重（木 86 + sub 42）
- 底下有一层极轻的 pad（每段换和弦），只在没人说话的时候垫住空气

解说 10 句（`say -v Tingting`），在 sound.py 里按时间摆位，并在人声处把配乐压低 62%。

## 怎么重跑

需要先把 onetake 的 `lib/motion.js` 与 `scripts/` 拷到手边（**motion.js 不进这个仓库**，
它是 PolyForm Noncommercial 授权的第三方库；这份仓库只留我们自己写的 comp / sound / 说明）：

```bash
git clone https://github.com/feitangyuan/onetake.git /tmp/onetake
cp /tmp/onetake/lib/motion.js docs/promo/onetake/
cd docs/promo/onetake
python3 sound.py                                                            # → sfx.wav
python3 ../../scripts/render.py comp.html --out draft.mp4 --sfx sfx.wav    # 1080p30 草稿
python3 /tmp/onetake/scripts/render.py comp.html --out film.mp4 --final --sfx sfx.wav  # 4K60（验收之后才跑）
python3 /tmp/onetake/scripts/probe.py comp.html --out probe      # 连续性 / 曲线
python3 /tmp/onetake/scripts/verify_promo.py film.mp4 --comp comp.html --shots 0.6,5.9,10.4,13.4,20.8,26,33,44,52,58
```

## 这笔片子踩过的坑

1. **手写透视会把纸箱画成漏斗**。第一版自己算 `k=f/(f+Z)`，四个侧面朝内收，像个桶。
   换成正交 + 偏航（`proj()` 里那一行）之后，两个侧面和顶面同时可见，才像一个立着的纸盒。
2. **箱底必须和屏幕一样大**。之前箱底 820×1400、屏幕 720×1280，钻进去之后两侧露出米色边，
   像手机壳卡了一圈纸板。现在两者同尺寸，屏幕就是箱底。
3. **盖板长度写成了两倍**。闭合时伸出箱子一倍远，整个画面被一块纸板盖住。
4. **压平时逐面混黑会过一层脏绿**（kraft 和 #0d0b09 混到一半是灰绿）。改成最后整块画布淡到黑。
5. **翻面不能只把宽度缩到 0**。第一版 privacy 面板 `scaleX→0.035`，整个下半场都是一条竖线，
   清单从来没出现过。改成绕左边缘 `rotateY(−92°→0)`，才是「同一张纸翻过来」。
6. 设置页顶部那两个「自定义/免费」按钮：**App 里样式是写死的**（`OutlinedButton` / `Button`
   不跟 `useFreeModel` 走），真机上永远显示「免费模型」被选中。这份复刻里按真实状态画了。
