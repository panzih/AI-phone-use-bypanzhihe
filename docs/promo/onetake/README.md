# 纸盒 · 装一个 APK 就行（60 秒 · 一镜到底 · 无旁白）

用 [onetake](https://github.com/feitangyuan/onetake) 做的产品短片。**没有解说**——全片只有
纸的声音、字，和一个纸箱。

- 成片：`../纸盒-一个纸箱-60s.mp4`（1920×1080 · 30fps · 60.0s · H.264 + AAC）
- 画面：`comp.html`（一份 HTML，`window.__seek(t)` 是纯函数）
- 声音：`sound.py` → `sfx.wav`（94 个合成音效，共用一个混响房间；**没有人声**）

## 一句话说的结构

**纸 → 字 → 界面 → 纸 → 字**：开场是贴着箱盖看的纸纹，镜头拉开才看清是个纸箱；
箱盖掀开，镜头钻进去，箱底那块面就是屏幕；屏幕上的一句话把整个 App 跑了一遍；
最后一切折回箱子、合盖、压平，压平的那块纸上长出「纸盒」两个字。

## 关于「没有旁白」

上一版配了 `say` 的中文朗读，被判定「太差劲」。这一版把人声整个拿掉：

- 片子里**所有要说的话都在画面上**（「说一句话」「自己看 / 自己点 / 自己走完」
  「模型自己选」「只在你手机上跑」「装一个 APK…」），字号 76–96px，一行只停 2–4 秒；
- 声音只剩纸和金属标记音：掀盖是 air + 木响，按下去是气泡，三条动作是三记玻璃音，
  三下重击是木 + sub，压平是一路往下抽的气；
- 没有旁白之后节奏完全由画面和音效决定，所以中段加了一段连击（20.4–23.0），
  全片不再靠"讲"来推进。

## 画面是怎么做出来的

不是录屏，也不是截图贴图——**一个 HTML，两个坐标系**：

- **纸箱**：canvas 2D 手写「正交投影 + 偏航」。正交的好处是每个面都是平行四边形，
  于是面内 UV 可以用一个仿射矩阵精确画：盖板上的 logo、名字、胶带、纸纤维都在这个
  变换里画，跟着箱子一起翻、一起压平。
- **界面**：DOM 复刻 0.10.7 的真实排版（720×1280），被相机矩阵缩放；
  缩放超过 2.4 倍时它自己铺满画面。
- **字**：屏幕坐标，不吃相机——大标题跟着镜头缩放就废了。

## 怎么重跑

需要先把 onetake 的 `lib/motion.js` 与 `scripts/` 拷到手边（**motion.js 不进这个仓库**，
它是 PolyForm Noncommercial 授权的第三方库；这里只留我们自己写的 comp / sound / 说明）：

```bash
git clone https://github.com/feitangyuan/onetake.git /tmp/onetake
cp /tmp/onetake/lib/motion.js docs/promo/onetake/
cd docs/promo/onetake
python3 sound.py                                                        # → sfx.wav
python3 /tmp/onetake/scripts/render.py comp.html --out film.mp4 --sfx sfx.wav --workers 5
python3 /tmp/onetake/scripts/verify_promo.py film.mp4 --comp comp.html \
        --shots 0.6,3.0,5.4,8.6,11.4,15.0,20.9,25.6,33.0,38.0,44.0,52.0
```

## 这笔片子踩过的坑

1. **手写透视会把纸箱画成漏斗**。换成正交 + 偏航之后才对。
2. **正交投影下每个面都是平行四边形**，所以「面内 UV」可以用一个仿射矩阵精确画。
3. **箱底必须和屏幕一样大**，否则钻进去两侧会露出米色纸边。
4. **大标题不能用世界坐标**。第一版字跟着相机缩放，镜头一推字就飞出画面；
   现在字层在 `#stage` 里，是屏幕坐标。
5. **一个 140px 模糊的大阴影会让每帧截图慢一倍**（0.88s → 0.37s）。
6. **字压在界面上要垫一层很软的黑纱**（`#scrim`），否则中文细笔划在深色 UI 上糊成一片。
