# 纸盒 0.15.0

> **换了一身衣服。** 功能、位置、交互都没动，改的是配色、圆角、字阶和按钮形状。

## 变了什么

**配色**

- 画布从暖米白提亮到 `#F7F5F0`，卡片改成**纯白**（原来是米白）；
  卡片和画布的层次靠明度差拉开，不再依赖一圈描边；
- 主色从松墨绿 `#186A56` 加深到 `#0E5C46`，按钮上的字更稳；
- 描边、分隔线整体减淡一档（`#E2DCD0` → `#E7E2D6`），列表看起来更轻；
- 深色模式同步调整：画布更深、卡片更亮，主色提亮到 `#6BD3B0`，对比度不变。

**圆角**

- 阶梯从 6 / 10 / 14 / 20 / 28 改成 8 / 12 / 18 / 24 / 30；
- 卡片 20 → 24，输入框与行内高亮 14 → 18，对话框与底部输入栏 28 → 30；
- **按钮改成胶囊**（主 / 次要 / 危险三种都是），文字按钮保持小圆角；
- 返回键、抽屉入口、图标底从圆形改成圆角方块，圆角随尺寸等比缩放。

**文字**

- 页面大标题 24 → 25sp，区块标题 19 → 20sp，次要正文 14.5 → 15sp，角标 11.5 → 12sp；
- 行高随之微调（正文 26sp、次要正文 23sp），字号阶梯的间隔比之前更清楚。

**间距与尺寸**

- 设置行最小高度 60 → 64dp，行与行之间松了一点；
- 按钮高度 52 → 50dp，胶囊左右留白 20 → 24dp；
- 卡片内上下留白 4 → 6dp；提示条左侧色条 3 → 4dp。

## 没变什么

- 页面结构、控件顺序、按钮位置、点击区域全部保持原样；
- 所有功能、权限、定时任务、副屏、语音输入照旧；
- 设置项与数据格式未变，0.14.1 → 0.15.0 直接覆盖安装即可。

## 验证

- CI：单测、lint、debug 构建通过；
- Release：`assembleRelease` 出正式签名包，`apksigner` 指纹校验非公开开发者密钥。
