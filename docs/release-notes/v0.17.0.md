# 纸盒 0.17.0

> **默认值按你的习惯调好了，应用内不再有任何"检查更新"的入口。**

## 默认值调整（新装即生效，老配置一次性升级）

| 项 | 旧默认 | 新默认 |
|---|---|---|
| 最大步数 | 30 | **99**（滑块最右仍是"不限"） |
| 开启记忆 | 关 | **开** |
| 点击前复核 | 关闭 | **只复核坐标点击**（中间档） |
| 语音输入 | 关 | **开**（点麦克风仍要过系统录音授权） |

- 老版本用户盘上存的还是旧默认时，会在首次读取设置时**一次性**抬到新值
  （`defaults_revision` 标记，只跑一次）。自己调过的值不动 ——
  例如你设过 50 步，它不会被改成 99。
- 记忆默认打开后，每次任务结束会多一次纯文字的归纳调用（成本很小）；
  不想要就关掉，关掉不会影响已有记忆。

## 删掉所有应用内更新入口

按你的要求，检查更新这条链路从界面上**和代码里**一起删掉了：

- 「关于」页不再有"检查新版本"和"启动时自动检查"两行，副标题也回到"版本与开源许可"；
- 启动时的自动检查、下载、安装、跳过版本全部移除；
- 删掉 `update/UpdateChecker.kt`、`ui/UpdateDialog.kt` 及对应单测；
- 连带去掉 `BuildConfig.ENABLE_UPDATE`、Gradle 的 `-PenableUpdate` 开关、
  `REQUEST_INSTALL_PACKAGES` 权限，以及 FileProvider 的 `updates/` 路径。

也就是说：**应用不会再联网查版本，也不会把 IP / User-Agent / 设备标识发给更新服务**。
新版本仍然从 GitHub Releases（或更新站网页）拿。

## 未变

- 动作协议、模型通道、免费车道、权限页、定时任务、副屏、录制均未改动。
- 版本号 0.17.0 / versionCode 90；可直接覆盖安装（正式签名线未变）。
