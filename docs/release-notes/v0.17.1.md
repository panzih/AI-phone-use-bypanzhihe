# 纸盒 0.17.1

> **把"怎么操作手机"这份说明书重写了一遍：同样的长度，少绕弯，少误导。**

这一版没有新功能，改的是模型每一步都会读到的那份系统提示词。

## 改对了三处会带偏操作的地方

| 原来 | 现在 |
|---|---|
| 浏览器一节写"三条信息源"，下面却列了四条 | 改成四条，并写清各自的代价 |
| 查包名写成 `list_apps`，看起来像一个动作 | 明确成技能：`"use_skill":"list_apps"` |
| 输入文字没提前提条件 | 写明"先 tap 输入框，再 input_text" |

## 把端侧本来就在做的事写进说明书

- 点支付 / 转账 / 删除 / 发送 / 授权，输入验证码或密码，**可能被端侧直接拦下**；
  被拦时不要换个说法硬试，需要用户确认就如实结束。
- 同一轮最多要 **2 次截图**、调 **3 次技能**；一批最多执行 **6 个动作**。
- 打开浏览器 / 换屏 / 批量收集 / 关闭弹窗 / 闹钟短信导航分享这类动作，
  执行完会**立刻把控制权交回模型**，排在后面的动作本轮不会执行。

## 少重复，省 token

- "这一屏为什么没有元素列表"的四种原因（副屏 / 无障碍没生效 / 纸盒自己在前台 /
  界面真的没有控件）不再在提示词里各写一遍，改由每一步的消息**按实际情况说明**。
- 第一步的通道说明也只保留"副屏现在能不能走"这类当次才知道的信息。

## 兼容性

- 动作名、JSON 字段、解析与执行逻辑不变，可直接覆盖安装。
- 提示词协议版本 9 → 10：升级后第一次发任务会按新上下文开始（旧对话的缓存前缀
  从第 0 个 token 重新建立），这是有意为之，不是丢历史。
- 版本号 0.17.1 / versionCode 91。
