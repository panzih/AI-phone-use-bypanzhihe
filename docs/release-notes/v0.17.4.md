# 纸盒 0.17.4

> **「正在总结记忆」改成对话里的一条普通消息。**

0.17.3 把它做成了输入栏上方的状态条。这一版改成对话流里的消息：

## 现在的样子

任务完成卡出现之后，下面会多出一条「记忆」消息：

```text
AI  记忆
    正在总结记忆…
```

总结完成后，**同一条消息**就地变成：

```text
AI  记忆
    记忆总结完成：常用设置页在第二屏
```

没有写入时会在括号里说明原因，例如「和已有记忆重复，已跳过」。

## 细节

- 同一条消息原地更新，不会先冒一条「正在总结」再冒一条「总结完成」。
- 不再弹「已新增记忆」toast，状态只留在对话里。
- 记忆开关关着，或这段任务没有可归纳的轮次时，不会出现这条消息。

## 兼容性

- 动作协议、提示词版本、解析与执行逻辑不变，可直接覆盖安装。
- 版本号 0.17.4 / versionCode 94。
