# 纸盒 0.17.3

> **任务结束后，底部会显示「正在总结记忆…」。**

以前任务一结束，按钮就回到「发送」，但记忆归纳还在后台跑一次模型。
这段时间界面看起来什么都没发生，用户只会觉得软件莫名其妙多了一次调用。

## 现在

任务结束后，输入栏上方会出现一条带转圈的状态：

```text
◌ 正在总结记忆…
```

- 归纳完成（无论写没写进去）就消失；
- 连续结束多个任务时，会等所有排队 / 进行中的归纳都结束才消失；
- 记忆开关关闭、没有可归纳的内容，或归纳失败时，同样会正常消失，
  不额外弹提示，原因仍可在运行日志里查。

## 兼容性

- 动作协议、提示词版本、解析与执行逻辑不变，可直接覆盖安装。
- 版本号 0.17.3 / versionCode 93。
