## 0. 总原则

1. **不改用户未提交的改动**：工作区已有 `LlmClient.kt` 的文案改动，视为用户工作，不覆盖。
2. **每完成一项，跑一次 `:app:testDebugUnitTest`**；涉及构建的再加 `assembleDebug`。
3. **发布签名链（原第 1 项）暂不做**：用户尚未确定正式签名方案，不擅自生成/替换 release keystore。
4. **发布工程化（原第 15 项）暂不做**：依赖正式签名方案，先搁置。
5. **可以“先做能力、后做发布”**：免费通道保留，但默认改走自定义 Key；高风险动作默认拦截，提供显式开关。

## 2. 关闭任务注入面（原第 2 项）

- [x] 2.2 定时任务入口统一走**非导出**的 `ScheduleReceiver`（只接受 `ACTION_FIRE`），任务内容经进程内 `PendingRunTask` 交接，不放进 Intent

- [x] 2.4 增加 `PendingRunTaskTest`：令牌缺失/错误取不到任务、令牌一次性、旧令牌失效；`adb shell am start ... --es run_task ...` 只会普通启动，不再触发任务

**完成记录（2026-10-28）**

- 新增 `schedule/PendingRunTask.kt`：任务只存本进程内存，主界面凭一次性随机令牌取走；令牌不匹配时原样保留，普通启动不会误跑定时任务。
- `ScheduleReceiver`：闹钟 `ACTION_FIRE` 触发时 `PendingRunTask.offer(...)` 一次，通知点击与直接拉起 `MainActivity` 共用同一枚令牌；Intent 里只带令牌，不带任务正文。通知点击用 `PendingIntent.getActivity`，避免“接收器再启动 Activity”被后台启动限制拦截。
- `MainActivity`：删除 `EXTRA_RUN_TASK` / `EXTRA_SCHEDULE_ID` / `EXTRA_SCHEDULE_VIRTUAL_DISPLAY` 的读取，改为 `PendingRunTask.consume(token)`。
- `AndroidManifest.xml`：MainActivity 注明“导出仅为启动器”，定时入口仍保持 `exported=false`。
- 验证：`./gradlew :app:testDebugUnitTest --offline --console=plain` → 276 个测试，0 失败（新增 3 条交接令牌测试）。

- [x] 7.1 任务状态从 Composable 迁到 ViewModel/状态持有类

**完成记录（2026-10-29）**

- 新增 `task/TaskHost.kt`，挂在 `PaperboxApp.taskHost`：运行状态、日志、对话、模型历史、上下文快照与**应用级协程作用域**都在这里。主界面只订阅同一份 State。
