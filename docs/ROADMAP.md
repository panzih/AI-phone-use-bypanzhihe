优先级原则：**先补测试兜底（防回归），再修低风险小坑，需要真机或外部输入的排最后**。

## 1. 测试兜底

- [ ] **入口层测试**：`submit()` / `runTask()` 这一层，覆盖 免费 / 自定义 × 有 Key / 无 Key 四种组合。
  断言的不只是"有没有提示"，而是**任何提前 return 的分支，都不许去停一个刚 `startForegroundService` 还没 `startForeground` 的服务**——0.10.6 那个"点发送就崩"就是死在这条路径上，而 237 例单测全绿也没抓到，因为现有测试都在测纯函数。
- [ ] **任务中途消息的回归测试**：现在运行中发消息会被直接吞掉，输入被清空且没有提示（见第 3 节）；改行为时先补一条能复现的测试。

## 2. 小修（低风险，可攒一批）

- [ ] **Key 加密失败不再静默存明文**：现在是 `SecretCrypto.seal()` 加密异常时原样返回明文，只写一条日志。
- [ ] **设置页"模型模式"加选中态**：选了自定义，"免费"按钮还是实心高亮。

## 3. 体验问题

- [ ] **键盘遮挡悬浮条**：发送后应收起键盘，悬浮条跟随输入法上移（现在会被键盘压住、按钮位置乱跳）。
- [ ] **任务运行中发的消息不再被静默吞掉**：现在直接 return，输入被清空且没有任何提示。
- [ ] **副屏连续多步没画面就中止**：现在只提示不计数，会一直盲点到模型自己宣布完成。
- [ ] **导出日志兜底 + 进度**：手机上没有能接收分享的应用时拿不到 zip；几十条记录导出要 20 多秒且没有进度。
- [ ] **定时任务页**：24 小时表盘 12/24 两套数字重叠；分钟要连点两次才选中；选了过去的时间静默顺延到次日；保存后键盘常驻。
- [ ] **关于页项目地址**：超一行被截断，不能点也不能复制。
- [ ] **首次安装的权限引导**：README 写"按引导开无障碍"，实际没有引导页，权限入口藏在侧边抽屉里。
- [ ] **录制入口的实验开关**：0.9.23 下架时承诺"设置里留一个实验功能开关"，实际只有硬编码常量，开关从未做出来。

## 4. 需要真机或外部输入

- [ ] **提示词里的身份段落**：`AppInfo.BILIBILI_URL` 还空着，拿到作者 B 站主页地址后再补，并同步提示词版本号。

## 5. 明确不做

- **高风险动作的强制人工确认**：不做"每次支付/发送/删除前都弹一次确认"。
  现行策略是：**默认直接拦截**；用户在设置里显式打开「允许 AI 执行高风险操作」后，
  每个高风险动作仍要过一次**独立的模型二次确认**（请求失败/输出无法解析一律拒绝，fail closed），
  结果写进运行日志。这样默认状态不会无限制执行，也不需要用户每一下都盯着点确认。
- **端侧自主决策**：端侧只执行云端点名的动作；端侧弹窗规则只给建议，点不点由云端决定。
  结论性判断只做建议，最终决定权归模型。
- **引入第三方运行时依赖**：运行时只用 AndroidX + Shizuku，不加网络框架、依赖注入框架。
  `androidx.test` 只用于 `androidTest`，不进 APK。

## 6. 已知限制（不是 bug，别当 bug 报）

- 副屏上的窗口不会交给无障碍，所以副屏只能靠截图 + 坐标，没有元素编号列表。
- `FLAG_SECURE` 的页面（支付、银行）截不到图，副屏上会黑。
- `input text` 不支持中文，模拟器输入法也只有英文，驱动界面时只能敲 ASCII。
- 免费通道有速率限制，额度用尽时网关返回 429；换个时间段或填自己的 Key。
- 上下文缓存是"完整匹配一个缓存前缀单元"，中间断一条就从断点起全废，所以不能随意裁剪历史。
- 内置浏览器只放行 http/https；`file://`、`intent://`、自定义 scheme 会被拒绝。
- 公网明文 HTTP 默认拦截；本机/局域网地址不受影响。
