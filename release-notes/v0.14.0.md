# 纸盒 0.14.0

> **可以说话了。** 这一版加了语音输入：在设置里打开，输入框右边就多一个麦克风。

## 怎么用

1. 打开「设置 → 行为 → 语音输入」，把开关打开；
2. 到「权限」页把「麦克风」开一下（没开时点麦克风会直接带你过去）；
3. 回到主界面，点输入框右边的麦克风开始说，说完再点一下；
4. 识别出的文字会**填进输入框**，确认或修改后点发送。

识别结果不会自动发送 —— 口误、同音字可以先改，避免说错一个字就执行错动作。
输入框里已经有草稿时，识别结果会接在后面，不会覆盖你已经打的字。

## 它是什么样的

- 说话时输入框上方显示 `正在听… 0:12`，麦克风变红；最多录 120 秒，到点自动收尾；
- 录完显示 `正在识别…`，成功后文字进输入框；
- 失败会在同一条状态条上说明原因：没填 Key、Key 不对、网络不通、服务繁忙、
  录音太短没听清，都分别有对应提示。

## 需要知道的几件事

- **要 DeepSeek 的 API Key**：「模型 → API Key」里那个。语音识别是 DeepSeek
  官方工具接口，**免费通道不含这项能力**，开着免费通道时界面会直接说明；
- **录音会发到 DeepSeek**：只在你点麦克风时采集，点结束立即停止，关掉语音输入
  开关会丢弃正在录的内容；
- **按音频时长计费**：ASR 按小时计价（具体见 DeepSeek 开放平台），一次识别
  最长 2 分钟；
- 接口地址沿用「模型」里填的地址。默认的 `https://api.deepseek.com` 直接可用；
  如果填的是公网明文 `http://`，请求会按既有安全策略在发送前拦截。

## 升级

- 已经在用旧版：装 `-legacy.apk` 直接覆盖，设置、对话、记忆都保留；
- 新用户或愿意卸载重装：装 `-official.apk`，走正式签名线。

本版没有数据格式变化，0.13.0 → 0.14.0 不需要迁移。已确认语音输入默认关闭，
不打开不会申请麦克风权限，也不会采集任何音频。
