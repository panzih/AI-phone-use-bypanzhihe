# 纸盒 0.14.1

> **只发正式签名包。** 功能与 0.14.0 完全相同，这一版只调整发布方式。

## 安装包变化

- 从 0.14.1 起，Release 只提供一个**正式签名**的安装包，不再提供
  `-legacy.apk`（开发者 Debug 签名）；
- 还在用 0.13.0 及更早版本、或之前装过 legacy 包的用户：签名不同，
  **不能覆盖安装**。需要先卸载旧版，再装这个包；卸载会清空本地设置、
  对话和记忆；
- 已经在 0.14.0 正式签名线上的用户：直接覆盖安装，数据保留。

## 为什么要这么做

0.12.5 及更早的包用的是仓库里公开的开发者密钥，任何人都能签出同签名的包
来覆盖安装，不能代表官方发布。0.13.0 起正式线换成了独立私钥，同时保留了
一条 legacy 兼容线做过渡。现在过渡结束：发布只保留正式签名这一条线，
以后每个 Release 都只出一个包。

## 功能

与 0.14.0 一致，包括：

- 语音输入：设置 → 行为里打开，输入框右侧出现麦克风；录音经 DeepSeek ASR
  转成文字填进输入框，确认后再发送；
- 界面、记忆、定时任务、副屏、高风险动作闸门均无变化；
- 数据格式未变，0.14.0 → 0.14.1 不需要迁移。

## 验证

- CI：单测、lint、debug 构建通过；
- Release：只执行 `:app:assembleRelease`，`apksigner` 校验确认证书指纹
  不是仓库里那把公开的开发者密钥。
