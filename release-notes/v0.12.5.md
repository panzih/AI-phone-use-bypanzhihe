# 纸盒 0.12.5

> **免费模型回来了，而且是两条车道。** 设置里选供应商即可，不用账号、不用 API Key。

## 免费模型

设置 → 模型 → 「模型供应商」下拉，最前面现在有两项：

- **免费模型 · OpenCode（无需 Key）**
- **免费模型 · Kilo（无需 Key）**

选中后不需要填接口地址和 API Key，模型清单从各自网关实时读取。

### OpenCode 车道

报文按上游最新整形层（v2.8.3 / opencode2api v1.4.7 移植）重做，修掉「IP 干净却提示额度用尽」的问题：

- 族路径端点、最新客户端 UA；
- `x-opencode-project` 改为按会话派生的 40 位 hex，不再共用会被预烧的 `global` 桶；
- 补齐 `traceparent` / `b3` 追踪头；
- system 注入官方 CLI 全量提示，tools 补齐官方 13 个工具；
- 流式补 `stream_options.include_usage` 与 `max_completion_tokens`；
- 会话改用慢钟铸造，时间窗过期会自动重铸。

当前免费池 12 个模型：DeepSeek V4.1 Flash、GLM 5.3 Flash、MiMo V2.6 Flash、MiniMax M3.1 Flash、Nemotron 3.5 Super VL / Lightning、LongCat 2.5、Iceman、Inkling 2 Small、Beam、Flint 40B、Big Pickle。

### Kilo 车道（新增）

Kilo AI 公共网关的免密免费池，不需要任何凭据：

- 模型清单实时读取 `isFree` 条目，当前 14 个；
- 对话走 OpenAI 兼容的 `chat/completions`，SSE 流式；
- 思考强度按 `reasoning` 对象下发（low / medium / high，支持关闭的模型发 `enabled:false`）；
- **单模型日限额自动兜底**：某个模型返回 429 时自动切到会轮换的 `kilo-auto/free` 重试一次，不会直接把 429 抛给用户。

> Kilo 免费池的 prompt 可能被上游记录并用于改进服务，不要发送敏感内容。

## 其它修复

- 浏览器通道的「普通点击仍留在浏览器」单测不再依赖真实窗口，CI 恢复全绿；
- CI 单测加 `--rerun-tasks --no-build-cache`，避免 Gradle 缓存命中造成「没测却显示绿」；
- CI 失败时直接列出挂掉的类 / 用例 / 报错，不用下载报告猜原因；
- 打 `v*` 标签会自动构建 Release 并上传 APK。

## 安装

- 直接安装：把 `AI-phone-v0.12.5.apk` 传到手机，允许「未知来源」，覆盖安装保留设置与对话。
- adb：`adb install -r AI-phone-v0.12.5.apk`
  （Android 15 上覆盖安装可能解绑无障碍服务，装完到「权限」页重新开启。）

## 升级提醒

- 签名没有变化（开发者签名），可以直接覆盖 0.12.4 及更早版本；
- 数据格式未变；
- 老配置默认仍停在 OpenCode 车道，想用 Kilo 到「设置 → 模型 → 模型供应商」里选；
- OpenCode 车道对客户端指纹敏感，若提示额度用尽可先切 Kilo 免费池。
