## 简介

```
同样能替你操作手机，功能一样、效果一样。
差别在它有多大。

▸ 安装包　　3.6 MB　 vs　220.7 MB　（差 61 倍）
▸ 装好之后　3.6 MB　 vs　约 1 GB　　（差 280 倍）
▸ 系统提示词　6,102 字 / 185 行　vs　整套引擎的提示与工具定义

数字不是估的：
· 纸盒的包是本机 assembleRelease 产物，3,819,555 字节
· 装好后的占用，是模拟器上 du -sk 量出来的
· 对手的数字，取自它 GitHub 的 latest release 与 README 原文

口径说清楚：
· 两个包都是 arm64，不是拿精简版比完整版
· 对手那 1 GB 是「本机模式」才要的 —— 它得在手机里装 Ubuntu + Node 才能跑整套引擎，
  只连电脑的话不用装。它大不是虚胖，是把一整套运行环境搬了进来
· 提示词那一格没拿到对手的可信数字，所以只给了纸盒这边的实测值，没有硬凑倍数

纸盒 0.17.3 · 安卓端 AI 操作手机 · MIT 开源
github.com/panzih/AI-phone-use-bypanzhihe
```
